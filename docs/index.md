# pypkgtest

Welcome to the documentation for pypkgtest.

## Distance Functions

The package provides several distance calculation functions:

*   `euclidean`: Euclidean distance between two arrays.
*   `manhattan`: Manhattan distance between two arrays.
*   `chebyshev`: Chebyshev distance between two arrays.
*   `minkowski`: Minkowski distance between two arrays.
*   `cosine`: Cosine distance between two arrays.
*   `gower`: Gower distance between two arrays for numeric features.
